## 目录

## 一切从 DeepSeek 开始

DeepSeek 是我开启 AI 探索之旅的起点。

众所周知，它很火，官网对话还免费，所以难免好奇，想去试一下。这是我最先接触的一个 AI。其实挺有意思的，哪怕只是简单的问答都很有趣——它知道很多我不知道的东西。一开始我的对话漫无目的，然后逐步在对话里获取新信息，发现一个又一个新的知识点、一片又一片新的领域，再通过 DeepSeek 进一步了解下去。

从单纯满足好奇心的角度来说，它让我觉得 AI 是真的不错：它相当于是**自我思考的拓展和延伸**——你思考得越多，通过 DeepSeek 反馈出来的东西就越多。

这恰好印证了 DeepSeek 官网的那句标题：

> DeepSeek —— 探索未至之境。

它大大满足了我的好奇心，为我打开了许多大门。我在对话里了解到不少相关细节，也慢慢冒出一个念头：**我能不能直接对 DeepSeek 官网做点什么？**

## 我想「动手脚」，于是认识了油猴

我想美化它的界面，想控制网页的一些行为。顺着这个需求，我了解到一个强大的工具——**油猴脚本（Tampermonkey，用户脚本 Userscript）**。

### 油猴脚本到底是什么

简单说，油猴脚本就是一段**在指定网页上自动运行的 JavaScript**。浏览器本身只负责展示网站，而油猴相当于给你开了一个「后门」：每当你打开匹配的网页，它就把你的代码注入进去，于是你可以：

- 改变网页的**样式**：颜色、字体、布局、背景，想怎么改怎么改；
- 改变网页的**行为**：自动点击、折叠元素、拦截网络请求、保存数据；
- 给网页**增加原本没有的功能**：设置面板、自定义按钮、本地存档……

它之所以叫「用户脚本」，是因为**网站不是你的，但你可以在自己的浏览器里决定它长什么样**。同一份脚本，任何安装了它的人打开那个网页，都能得到同样的增强效果。脚本通过文件开头的一段注释声明自己在哪些网址生效，比如：

```javascript
// ==UserScript==
// @name         DeepSeek 全功能增强
// @match        https://chat.deepseek.com/*
// @grant        GM_setValue
// ==/UserScript==
```

`@match` 决定它在哪些页面运行，`@grant` 申请浏览器扩展提供的特殊能力（比如跨页面保存设置）。脚本本身是纯文本，装一个「脚本管理器」扩展就能运行，最主流的管理器就是 **Tampermonkey（油猴）**，同类还有 Violentmonkey（暴力猴）。

想玩的话，你需要一个**支持扩展的浏览器**。电脑上 Chrome、Edge、Firefox 都可以；手机上麻烦一点，我推荐：

- **Microsoft Edge（安卓 / iOS）**：安卓版已经支持扩展，在扩展商店里搜 Tampermonkey 安装即可，是我最推荐的手机方案；
- **Firefox 安卓版**：附加组件里直接有 Tampermonkey；
- **Kiwi Browser**：基于 Chromium、能直接装 Chrome 商店扩展（适合喜欢 Chrome 生态的）。

## 让 AI 写脚本？结果是惨烈的

最初，我很自然地想：那就直接让 DeepSeek 给我写一个油猴脚本呗？

结果是惨烈的。因为**信息来源不足**——针对一个真实网页写增强脚本，必须知道这个网页**真实的 DOM 结构**：输入框是哪个元素、消息气泡是什么类名、网络请求长什么样。AI 凭空猜出来的选择器，一跑就对不上，页面一改版更是全盘皆输。

所以过程很波折。后来有了那种**真正能干活的 Agent**：它能自己打开浏览器、登录网站、把页面结构一点点探查清楚，再基于真实结构写代码、自己跑测试验证，才勉强做出了几个能用、也看得过去的脚本。但也只是差强人意。

辗转经过好几个 Agent、推翻重写了好几版之后，才有了现在这个我自己比较满意的版本——**DeepSeek 全功能增强**。

## 这个脚本都做了什么

脚本的设置按钮就放在输入框上方、**「深度思考」和「联网搜索」按钮的旁边**，是一个小小的齿轮，点一下弹出设置面板，手机上也专门做了适配，不会超出屏幕。下面这些功能，每一个都有独立开关。

### 自定义背景：让对话页变成自己的

可以直接填一张**图片 URL** 当全局背景，自带一张蓝色绣球花的深色默认图；还能调亮度、模糊度，切换时图片会**预加载好再淡入**，不会出现一点点填充的割裂感。顶栏也可以在「磨砂玻璃」和「背景直接透出」两种风格之间切换——我更喜欢后者，菜单和按钮轻轻浮在花上，整个页面是通透的。

![美化后的欢迎页：蓝色绣球花背景、磨砂输入框、悬浮的模式按钮](https://s41.ax1x.com/2026/09/08/pnEdQvq.jpg)

### 水玻璃气泡与磨砂输入框

用户和 AI 的消息都做成了**水玻璃（glassmorphism）质感的气泡**，有模糊、饱和和一层内发光，深浅色模式下都调过；输入框则是悬浮起来的磨砂玻璃，和底部留出安全距离，不会贴死，也不会露出黑边。

### Markdown 与公式渲染

DeepSeek 本身就用 Markdown 回复，我把它的渲染样式**整体重新美化了一遍**：标题、引用、表格、代码块（复制按钮保留）、任务列表、分割线……另外我发现官网**其实并不渲染 LaTeX 公式**，`\( \)`、`$$` 会原样显示成文本，于是内置了一套**离线的 KaTeX 渲染引擎**（字体全部打包进脚本，不请求任何外部服务器），行内、行间公式都能正确显示，同时和官网自带的 mermaid 流程图兼容。

![对话页：水玻璃气泡、美化后的 Markdown 引用与列表、磨砂输入框](https://s41.ax1x.com/2026/09/08/pnEdM2n.jpg)

### 思考过程自动折叠

AI 的「深度思考」过程默认**自动收起**，需要时再点开，节省屏幕空间；切换对话、流式输出新内容时也会自动处理，自己手动展开后则不会跟你抢。

### 防撤回：被删掉的回复，本地留档

DeepSeek 偶尔会把已经生成的回复撤回（内容过滤）。脚本会**拦截网络响应**：一旦检测到撤回信号，就把原本的回复**完整保存在本地**并继续展示，重新打开对话时再从历史接口里把它还原回来。提供两种模式：

- **智能模式**：只在需要时把被撤回的内容补回上下文，尽量节省 token；
- **全量模式**：所有历史撤回都完整带回。

### 按会话隔离的系统提示词

可以给**当前这一个对话**单独设置系统提示词，只对这个会话生效，不同对话之间互不混淆；提示词是在**网络请求层**注入的，不会出现在你的聊天气泡里，刷新、重新生成也不会泄露，但它在设置面板里完全透明、随时可看可改。

### 上下文用量进度条

DeepSeek 的上下文是有长度上限的。脚本会统计当前会话（**包括打开脚本之前就已经存在的历史对话**）用掉了多少 token，在设置面板里用一条进度条显示占比，临近上限时变色提醒你开新对话。

### 还有一堆细节

- 去掉「AI 生成」之类的标识、欢迎页多余的「下载应用」按钮；
- 保留并兼容官网的消息上下导航、用户长消息折叠展开；
- 顶栏分享按钮与标题区的背景统一，不再一条黑一条花；
- 全部功能**手机端优先**适配，同时兼顾电脑端。

## 怎么安装（手机 Edge 为例）

1. 在 Edge 里安装 **Tampermonkey** 扩展（菜单 → 扩展 → 管理扩展 → 获取扩展，搜索 Tampermonkey）；
2. 直接在浏览器打开下面的脚本直链，Tampermonkey 会自动弹出安装页，点「安装」：

> 脚本直链：<https://raw.githubusercontent.com/Hiweny/deepseek-enhance/main/deepseek-enhance.user.js>
>
> 如果 GitHub 直链打不开或下载慢，用这个加速镜像（在原链接前加 `ghproxy.net`）：
> <https://ghproxy.net/https://raw.githubusercontent.com/Hiweny/deepseek-enhance/main/deepseek-enhance.user.js>

3. 打开 <https://chat.deepseek.com>，点输入框旁的小齿轮就能开始设置。

以后脚本更新，Tampermonkey 也会自动提示。顺便说，**油猴脚本本身的可玩性非常高**：会一点 JavaScript，就能给任何你常用的网站做私人定制，入坑不亏。

## 懒得换浏览器？我打包了 APK

考虑到很多人不想为了一个脚本折腾浏览器和扩展，我又把同一份脚本**注入到一个 WebView 套壳 App** 里，打包成了安卓应用，名字叫 **DeepSleep**，图标是一只睡觉的小鲸鱼。

它不只是「开个网页」那么简单：

- **全屏沉浸**：内容一直铺到状态栏和手势条下面，没有黑线，对标官方 App 的观感；
- **开屏页**：加载网页的短暂白屏换成了居中的睡鲸 Logo，背景色跟随系统明暗；
- **主题跟随系统**：系统切深色，App 里的 DeepSeek 也立刻跟着切；
- **键盘适配**：唤起输入法时输入框会被自动顶起，键盘上**同时保留「换行」并多出一个「发送」键**，和主流聊天 App 一致；
- **系统级分享联动**：在任何 App 里选中一段文字 → 分享 → 选 DeepSleep，文字会自动填进输入框，类似官方的「问 DeepSeek」；
- 脚本在**页面任何代码执行之前**就注入完成，保证增强效果不闪、不丢。
